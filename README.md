# Кабинет сотрудника УПЧ

Рабочее место рядового сотрудника аппарата Уполномоченного по правам человека, который отвечает на жалобы граждан. Прототип для хакатона по кейсу ФГИС УПЧ. Вход через портал https://daria71321-netizen.github.io/fgis-upch-portal/ (роль «Сотрудник УПЧ»).

MVP: все обращения относятся к одному ведомству, **ФСИН России** (колонии и СИЗО). Данные демонстрационные.

## Что умеет

- **Обращения**: очередь жалоб, фильтры по важности, сроку, форме поступления и статусу, сортировка по важности или сроку.
- **Карточка**: форма поступления (электронно, бумажное, горячая линия), важность по ранжированию, рекомендуемый срок и максимальный срок по закону (30 дней, 59-ФЗ ст. 12), описание и анкета (Приложение 5 итогового документа), рекомендация ИИ (маршрут, проверки, правовые основания, варианты проекта ответа), редактирование жалобы и ответа с записью в историю, печать на бланке, подпись КЭП (имитация), отправка.
- **Новое обращение**: анкета для горячей линии и бумажных писем, автозаполнение анкеты по тексту, расчет приоритета на лету.
- **Мои показатели**: ответы за день и за 14 дней, средний срок, доля в срок, доля проектов ИИ без правок.
- **Сроки и правила**: памятка по срокам, формуле приоритета и электронной подписи.

## Команды

- `npm install`, `npm run dev`: локальный запуск.
- `npm run build`: проверка типов и сборка в `dist/`.
- Публикация: push в `main` запускает `.github/workflows/deploy.yml` (GitHub Pages, источник GitHub Actions).

## Устройство

- `src/config/reference.ts`: вопросы анкеты, категории прав, формула приоритета, сроки.
- `src/data/topics.ts`: типовые сюжеты жалоб на ФСИН, правовые основания, шаблоны.
- `src/data/seed.ts`: генератор демо-обращений (даты считаются от сегодняшнего дня).
- `src/data/ai.ts`: имитация ИИ (анализ, сроки, проект ответа, автозаполнение).
- `src/data/store.tsx`: состояние; изменения хранятся в браузере (localStorage), кнопка «Сбросить демо-данные» в меню.
