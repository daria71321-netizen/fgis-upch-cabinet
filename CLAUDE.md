# Кабинет сотрудника УПЧ (fgis-upch-cabinet)

Vite + React + TS + Tailwind 3, HashRouter, recharts, lucide-react. Base `/fgis-upch-cabinet/` в `vite.config.ts`. Описание в README.md, дизайн в DESIGN.md.

Правила текста интерфейса: русский язык, без буквы «ё», без длинных тире. Приоритет по модели «Ранжирование» (src/config/reference.ts). ИИ только рекомендует, все изменения сотрудника пишутся в историю карточки. Одно ведомство в MVP: ФСИН России.
